# Глобальные правила

## Язык

Все сообщения пользователю (статусы, пояснения, выводы) — только по-русски.

## Коммиты

- Не делать `git commit` без явного подтверждения пользователя на каждый конкретный коммит.
- Утверждённый план, где коммиты перечислены по шагам, подтверждением не считать — спрашивать перед каждым коммитом.
- `git push` — только по прямой просьбе.

## Время в шагах

В каждой статус-строке (шаге) в начале — метка времени: `[16.09 16:26] Проверяю тесты...`

- Метка на каждом шаге, а не только в начале хода; итоговая строка `result:` тоже с меткой.
- Время узнавать отдельной командой `date '+%d.%m %H:%M'`, не добавлять `date` к каждой команде.

## Скиллы

- В начале каждой задачи сверяться со списком доступных скиллов и вызывать
  подходящий через Skill сразу, не дожидаясь явной команды.
- При сомнении между «вызвать» и «не вызвать» — вызывать.
- После вызова следовать плейбуку скилла до конца задачи.

## Инструменты

- В Bash использовать `/usr/bin/grep` — обёртка `grep` падает
  («claude native binary not installed») и срывает конвейеры (`git status | grep`).
